**Agent：** 熟悉 ReAct / Plan-and-Execute / Reflexion 等范式；具备多 Agent 协作（Planner-Executor-Critic）与 Lead Agent 决策中枢、动态工具调度（Tool Dispatch）的落地经验；熟悉工具调用 schema 设计、参数校验、失败重试与死循环检测。

**LLM：** 熟悉 GPT-4 / Claude / Qwen 等模型选型与效果权衡；掌握 CoT、Few-shot、结构化输出（JSON Schema）等 Prompt 技术；熟悉上下文压缩与长期记忆注入。

**RAG：** 熟悉向量检索（FAISS / Milvus）与混合检索 + Rerank；有爆款知识库构建与主演/情节/主题多路召回的落地经验。

**评测：** 掌握 LLM-as-Judge、自建评测集与 badcase 归因；有「输入 + 决策 + 后效」基准集沉淀与离线反事实评估经验。

**可观测性：** 熟悉 Agent 链路追踪与决策留痕、决策-执行对账，以及成本与延迟监控告警。

**安全：** 熟悉 prompt 注入防御、内容审核、越权拦截与写操作幂等。
