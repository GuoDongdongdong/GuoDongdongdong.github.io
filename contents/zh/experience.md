#### 一、对话式创编 —— 创编Agent

- **背景：** 传统创编要求广告主在多个平台手动完成：选品、选素材、定出价来搭建广告物料，门槛高且步骤繁琐。
- **目标：** 搭建创编 Agent，通过现有的对客Agent（磁力青松）向广告主提供对话式创编能力，让广告主通过**自然语言多轮交互**完成广告创编。青松负责意图理解、参数抽槽和澄清追问。创编 Agent 负责权限校验、智能选品、建议出价和物料搭建；同时参与设计青松 AgentTask 长任务运行时，承载这类多轮 + 异步写操作的长任务。 
- **难点：**
  - 创编决策强约束：快手号 > 选品（书/剧）> 转化目标 > ROI 字段存在硬依赖与优先级，需在「客户指定优先」与「自动补全/替换」间安全消解
  - 自然语言创编是「多轮交互 + 异步写操作」长任务：意图→补参→推荐→确认→创建跨多次请求，创建结果异步返回，需状态持久化与恢复
  - 写操作安全：仅「确认」一次触发账户变更，需幂等防重复创建；创建超时结果未知不能盲目重建
- **我的职责：创编 Agent 决策 + 参与设计青松 AgentTask（Java 自研、无框架）**
  - **Java 自研、无框架**：创编 Agent、槽位状态机、规则引擎均从零实现，不依赖第三方 Agent 框架
  - **创编 Agent 决策**：意图识别、槽位抽取与选品/定向/出价决策，字段优先级消解、可投性校验、参数替换下沉到确定性规则引擎，模型输出不直接信任
  - **抽槽与澄清**：首次意图随 query 抽槽（可为空）、后续修改抽修改字段；表达指定但没说清 / 缺必填时澄清，给选项、留上限
  - **参与设计青松 AgentTask 长任务运行时**：事件驱动 + 持久化状态机（对齐 A2A TaskState），Checkpoint / Artifact 分离，普通单轮不走 AgentTask、仅长任务走
  - **幂等与并发**：trigger_key + task_version + row_version（乐观锁）+ lease（执行租约）+ executionId（A2A 幂等）
  - **两次 A2A 调用与结果兜底**：第一次推荐投放目标（不写 DSP）、确认后第二次创建（写 DSP）；confirmedTarget 从 Artifact 还原、不信任前端；超时结果未知走 getTask/executionId 对账，无保障转人工核实
- **项目收益：** 自然语言创编全链路可暂停、可恢复、可异步回调；写操作幂等杜绝重复创建（指标示例，待回填）

#### 二、智投Agent-投中辅助调控

- **项目背景：** 广告投放过程中「账户需要多少个计划/单元/创意（基建量）、是否调价、是否关停不起量物料」长期靠固定规则与静态阈值，无法适配账户生命周期（冷启/稳定/衰退）及不起量、超成本等场景。**目标：** 将投中基建决策升级为 LLM 驱动的智投Agent，实现账户级动态基建量决策与辅助调控。
- **项目难点：**
  - 决策到效果的归因链路长：基建量/quota 决策受精排、调价、大盘流量共同影响，直接用消耗做反馈信号会学偏
  - 硬约束与 LLM 自由度的边界：串包/串品等过滤规则是硬约束，绝不能交给 LLM，又需保证 LLM 输出不产出不合规物料
  - 线上调用量级大（素材优选日调用 743 万次），全量走 LLM 成本与延迟不可控
- **核心动作：感知-分析-决策-执行-反馈-迭代 五角色闭环**
  - **Java 自研、无框架**：五角色闭环、信号触发调度、共享 memory、反思循环（Generator-Reflector-Curator）均从零实现，不依赖第三方 Agent 框架
  - 构建投放数据感知器 / 策略协同决策者 / 自动化执行器 / 风险管控器 / 决策反思者五角色闭环，多信号触发（物料首次消耗/未过审/被基建/天级定时），输入账户层级（预算、余额）+ 物料层级（计划/单元/创意消耗），输出计划数/单元数/创意数 + 出价调节 + 关停决策
  - 范式选型 Reflexion（Generator-Reflector-Curator，模型用 Qwen）：Generator 出策略、Reflector 对照实际后效反思、Curator 沉淀教训反哺；反思 reward 用「是否起量/冷启通过/成本达标」等代理指标，按「账户生命周期 × 策略」聚合，规避归因混淆
  - 「LLM 出策略 + 规则/求解器出数值」：对 LLM 输出的基建量与 quota 做上下界护栏（clamp/归一化/总量校验），硬约束过滤保留确定性兜底
  - 基建Agent × 素材优选Agent 账户粒度串行异步协同，共享环境/基建/反思 memory
  - 成本触发分层：仅在账户级基建决策这一低频事件触发 LLM（而非每次物料填充），叠加语义缓存与小模型蒸馏
- **项目收益：** 素材冷启通过率、起量速度、非重复素材消耗占比、素材 arpu 等指标提升（示例，待 AB 回填）；相比全量 LLM 方案，单账户日 token 成本下降约 60%
