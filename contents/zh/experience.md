#### 磁力青松 Agent — Workflow 到 Agent Harness 架构升级

- **项目背景：** 磁力青松是快手广告平台（磁力引擎）的 AI 对话助手，面向广告主提供投放咨询、效果诊断、广告操作等 AI 能力。原有系统以**固定 Workflow 流水线**实现：节点顺序写死（意图识别 → 检索 → LLM → 回包），每新增一种业务能力就要修改主干流程，扩展成本高、链路脆；上下文管理、工具调用、记忆注入等横切逻辑散落在各节点中，难以复用。**目标：** 将平台 AI 能力从固定 Workflow 改造为 **Agent Harness** 架构，实现动态工具调度、统一上下文管理，同时以标准 RPC 接口对外开放。
- **核心改造：Workflow → Agent Harness**
  - **原 Workflow 模式**：Coordinator → Planner → 各专项节点（知识检索 / 效果诊断 / 出价调整 / 审核催审…）→ 回包，节点顺序固定，意图路由写死在主干，新增能力必须改流程图
  - **Agent Harness 模式**：改为由 **Lead Agent（LLM）统一决策**，system_prompt 动态注入当前可用工具清单（知识问答 / 效果诊断 / 流量预测 / 出价建议 / 催审等各专项 Action），Agent 根据用户意图自主选择工具链，通过 `ExecuteAction` 调度对应子 Agent 执行，结果回传 Lead Agent 汇总回包
  - **Middleware Chain 解耦**：将原本散落在各节点的横切逻辑（上下文加载、记忆注入、意图守卫、结果收敛）抽离为有序 Middleware 流水线，新增能力只动对应 Middleware 层，主干 Agent 推理代码零改动
  - **对外 RPC 入口**：在 Harness 之上封装 `AdJarvisSkillService`（gRPC），支持同步 `ExecuteSkill` 与流式 `ExecuteSkillStream`；每次请求按 standalone 模式独立建会话，通过 Kconf 动态配置可用 skill 白名单，无需改代码即可灰度扩展
- **我的职责：**
  - 主导 Harness 架构设计，完成从固定 Workflow 到 Lead Agent + 动态工具调度的改造方案
  - 实现 Middleware Chain，将上下文管理、记忆读写、意图守卫等横切逻辑从业务节点中解耦
  - 设计并实现对外 RPC 入口（`AdJarvisSkillService`）及 standalone 公共执行层，消除 skill 与 batchEvaluation 两条链路的重复逻辑
  - 完成意图守卫 + Kconf 灰度配置，支持按租户白名单放量，无需发版即可扩展可用意图
  - **上线效果：** 新增业务能力研发周期从原来"改主干 Workflow + 联调"缩短约 50%；对外 skill RPC 接口灰度发布后成功率 ≥ 99.5%，P99 ≤ 8s

#### 智能选品 Agent — 短剧大模型选品推荐系统

- **项目背景：** 快手短剧广告业务中，投放团队需要从海量短剧内容库中为广告主筛选出与其目标人群最匹配的短剧进行推广，原有选品流程以人工+规则为主，效率低、个性化程度有限。**需求目标：** 基于大模型构建智能选品 Agent，实现"输入广告主投放意图 → 自动分析人群特征 → 多维检索 + 排序 + 推荐"的端到端自动化选品链路。
- **技术架构：** 在快手 KFlow 工作流引擎基础上，将原有 Workflow 改造为 Agent 模式：
  - 意图解析：LLM 解析广告主输入（目标行业、人群画像、预算范围、投放目标），结构化抽取选品约束条件
  - 短剧画像构建：基于短剧内容、受众数据、历史投放效果构建多维向量化特征（题材 / 演员 / 调性 / 受众年龄性别层）
  - 检索与排序：向量相似度召回候选短剧集合 → 多路特征融合（内容匹配度 + 历史 CTR + 受众重合度）→ LLM rerank 生成推荐理由
  - ReAct 循环：Agent 可按需调用"短剧库搜索""受众分析""历史投放数据查询"等工具，直至找到满足约束的推荐结果
  - 结果呈现：结构化输出推荐列表（短剧基本信息 + 推荐理由 + 预期效果预估）
- **我的职责：**
  - 负责将原有规则 Workflow 改造为 Agent 架构，设计意图解析 → 工具编排 → ReAct 循环的完整链路
  - 设计短剧画像特征工程方案，接入内部向量检索服务，完成"意图约束 → 特征向量 → 候选召回"链路
  - 实现 LLM rerank 节点，基于广告主目标对候选集进行个性化重排并生成结构化推荐理由
  - 完成 Agent 工具注册（短剧搜索 / 受众分析 / 效果数据查询），支持 ReAct 多轮工具调用
  - **上线效果：** 选品效率相比人工流程提升 60%+，推荐短剧与广告主目标人群的受众重合度平均提升约 25%
